# 저장소 구조와 관례

## 환경

- Go 1.24.5, 모듈명 `termgun`, 모든 파일은 `package main`이다.
- 외부 의존성을 추가하지 않는다.
- 이 작업 공간은 git 복구를 전제로 하지 않는다. 기존 변경을 덮어쓰지 않는다.

## 코드 지도

| 파일 | 역할 |
|---|---|
| `main.go` | raw 모드, 고정 프레임 루프, 터미널 복구 |
| `game.go` | 시뮬레이션, 충돌, 피해, 아이템, 레벨업, 이벤트 |
| `render.go` | 카메라, 월드, HUD, 미니맵, 오버레이 |
| `dungeon.go` | BSP, FOV, flow field, 타일 |
| `enemy.go` / `elite.go` | 적 AI, 예고, 정예 능력 |
| `weapon.go` / `entity.go` | 무기와 엔티티 정의 |
| `rooms.go` / `props.go` / `pressure.go` | 특수방, 지형, 층 압박 |
| `move.go` / `math.go` / `zoom.go` | 이동 상태, 벡터, 배율 |
| `term.go` / `input.go` | 화면 버퍼, VT 입력 파싱 |

플랫폼별 파일은 [platform.md](platform.md)를 본다.

## 관례

- UI 문자열은 한국어, 코드 주석은 영어로 쓴다.
- 주석은 코드가 하는 일보다 직관에 반하는 선택의 이유를 설명한다.
- 플레이 영역은 ASCII만 사용한다. `+`는 의료 키트, `X`는 문이므로 글리프를 재사용하지
  않는다.
- 새 기능은 HUD, `?` 도움말 또는 글리프로 노출한다.
- 밸런스 값은 파일 상단의 이름 있는 상수로 모은다.
- 읽기 어려운 최적화는 프로파일 결과가 없으면 추가하지 않는다.
