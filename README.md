# termgun 2.0 - DEEP CORE

터미널에서 돌아가는 실시간 트윈스틱 로그라이크 슈터입니다. 키보드로 움직이고
마우스로 조준·사격하며 3개 구역, 15층의 심층 코어를 내려갑니다. Go 표준
라이브러리만 사용합니다.

```sh
# Linux
go run .
go build -o termgun .
./termgun -seed 42  # 같은 던전 재현
./termgun -fps 30   # 느린 터미널
./termgun -zoom 3   # 배율 1~4, 기본 2

# Windows (PowerShell)
go build -o termgun.exe .
.\termgun.exe -seed 42
```

최소 터미널 크기는 60x20이며 256색 지원이 필요합니다. 현재 문서와 개발 대상은
Linux와 Windows 10 이상입니다. Windows에서는 UTF-8과 ANSI 색상을 지원하는
[Windows Terminal](https://github.com/microsoft/terminal)을 권장합니다. PowerShell이나
명령 프롬프트에서 직접 빌드하거나, Linux에서
`GOOS=windows GOARCH=amd64 go build -o termgun.exe .`로 교차 빌드할 수 있습니다.
`-fps`는 15~1000, `-zoom`은 1~4 범위이며 잘못된 옵션 값은 실행 전에 오류로
보고됩니다.

## 조작

| 입력 | 동작 |
|---|---|
| `W` `A` `S` `D` / 방향키 | 즉응형 이동 (빠른 출발·급정지·반전) |
| 마우스 이동 / 좌클릭 | 조준 / 사격 |
| `Space` / 우클릭 | 짧은 대시 (반복 입력으로 연속 사용) |
| `1`–`6` / 휠 / `[` `]` | 직접 선택 / 사용 가능한 무기 순환 |
| `F` / 중클릭 | 현재 무기를 유지한 채 즉시 근접 공격 |
| `E` | 계단 이동·제단 교환 |
| `Tab` / `M` | 미니맵 |
| `?` / `H` | 도움말 (좌우키로 페이지 이동) |
| `O` | 설정 (상하키 선택, 좌우키 조정) |
| `P` / `Esc` | 일시정지 |
| `Q` / `R` | 종료 / 사망 후 재시작 |

입력은 `-input auto|kitty|device|compat`로 선택합니다. `auto`는 kitty 키보드
프로토콜, `/dev/input`, 호환 모드 순으로 시도합니다. 이 선택은 Linux에만 적용되며,
Windows에서는 콘솔의 키 누름·해제 이벤트를 직접 사용해 대각선 이동을 지원합니다.
`compat`는 키 해제 이벤트가 없는 환경을 위한 레거시 비상 모드이며 정상적인 게임
플레이를 보장하지 않습니다. 이후 조작 설계의 기준은 kitty, `/dev/input`, Windows
콘솔 같은 정밀 입력 모드입니다.

설정에서는 상하키로 항목을 고르고 좌우키로 조정합니다. 자동 일시정지, 게임 오버
시드 표시, 자동 무기 변경, 화면 흔들림, 화면 배율과 성능 디버깅 정보를 바꿀 수 있습니다.
일반 편의 토글은 기본적으로 켜지고 성능 디버깅은 기본적으로 꺼집니다. 같은 실행 안에서
재시작해도 설정이 유지됩니다. 성능 디버깅을 켜면 FPS, 프레임·업데이트·렌더·출력 시간,
힙·GC와 화면 객체 수가 플레이 화면에 표시됩니다.

## 기본 규칙

- 층마다 새 던전이 생성되며 깊어질수록 적과 난도가 강해집니다. B1~B5 정비 구역,
  B6~B10 배양 구역, B11~B15 반응로 구역으로 이어집니다.
- B5 오버시어, B10 매트리아크, B15 코어 워든이 계단을 봉쇄합니다. 코어 워든을
  처치하고 계단에서 `E`를 누르면 원정을 승리로 마칩니다.
- B5와 B10 보스를 쓰러뜨리면 결정타를 준 무기에 코어를 장착합니다. 무기 이름의
  `*` 표시는 진화한 무기입니다.
- 방은 가까운 이웃끼리 연결되고 여러 순환로를 가져 한 길만 강요하지 않습니다.
  배양 구역은 둥근 실험실, 반응로 구역은 기둥 엄폐물이 있는 전투 홀을 만듭니다.
- 미니맵은 현재 구역명과 발견한 보물방(`t`), 매복방(`!`), 제단(`$`)을 기억합니다.
  오래 헤매면 목표의 8방향, 거친 지도 구역, 정확한 위치 순서로 힌트가 열립니다.
- 대시는 에너지 30을 쓰는 짧은 회피 겸 공격입니다. 기본 에너지 100으로 세 번
  연속 사용할 수 있고, 누를 때마다 새 방향을 정합니다. 촘촘히 이으면 두 번째는
  125% 속도·3.75칸, 세 번째는 150% 속도·4.0칸이 기본이며 같은 방향으로 이으면 각각
  4.10칸·4.50칸까지 늘어납니다. 45도 전환은 직진 추가 거리의 절반만 받고, 90도 이상
  꺾으면 추가 거리 없이 기본 연속 대시만 적용됩니다. 공격을 스치면 [완벽 회피]로
  슬로모션과 에너지 20을 되돌려주지만 한 연속 대시 묶음에서는 한 번만 발동합니다.
  다만 눈치 빠른 가벼운 적(군집·자폭·치유사)은 흩어져 비켜서고, 추격 무리는
  좌우로 갈라져 포위합니다.
- 벽 너머는 보이지 않고, 한 번 본 지형은 어둡게 기억됩니다.
- 적을 처치해 경험치를 얻고 레벨업 때 특성 3개 중 하나를 고릅니다. 깊은 층의
  치유사(`m`)는 아군의 체력을 되돌리니 먼저 처리하는 편이 좋습니다.
- `+` 의료 키트, `}` 무기, `=` 탄약, `&` 최대 체력 증가 아이템입니다.
- `0` 폭발통, `%` 균열 벽, `~` 산성, `X` 매복방 문, `$` 제단입니다.
- 강한 공격은 예고 후 발동합니다. 예고가 시작되면 공격 방향은 고정됩니다.
- 체력 완전 회복 수단은 없고, 적 하나의 기대 회복량은 한 대 맞는 피해보다 작습니다.
- 자동 무기 변경이 켜져 있으면 탄약 소진 시 1번 권총으로, 권총도 비면 근접 공격으로
  전환됩니다. 무기나 탄약을 획득할 때는 현재 무기를 유지합니다.
- 오래 머물수록 층 보너스가 줄고 증원이 도착합니다.
- 배율은 표현만 바꾸며 같은 시드와 입력의 시뮬레이션 결과에는 영향을 주지 않습니다.
